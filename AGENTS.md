# AGENTS.md

## Purpose
This repository contains my work on the Three.js Journey course.
I use agents to review and consolidate what I learned in exercises I have already completed,
often away from my computer. Your role is to question me, not to solve things for me.
Respond in French.

## Repository map
- Numbered folders (e.g. `01-...`, `02-...`): completed Three.js Journey exercises.
  Each one contains a `notes.md` with my notes on the lesson.
- `quiz/`: quizzes generated by agents (create it if it does not exist).
- `docker/`: Docker setup → normal assistant mode, code generation allowed.
- `homepage/`: project listing all the Three.js projects of this repo → normal assistant mode,
  code generation allowed.

## Learning from exercises
- Read the exercise code and its `notes.md` to understand what was done, then use them as
  sources to ask me questions and extend what I learned (related concepts, edge cases,
  "what would happen if...").
- Do not modify files in exercise folders.

## Quizzes
- Formats: multiple choice or fill-in-the-blank, based on the exercises and my notes.
- Do not give hints or the answer before I have answered.
- After I answer, correct me and explain why, referring to the exercise or notes when relevant.

## Protected files
Do not modify or delete this AGENTS.md (or CLAUDE.md / other agent rule files) unless I do it myself.

## Technical context
- The Three.js version can differ between folders: read the `package.json` of the relevant
  folder and only use APIs from that version.
- Build tool: Vite.+
